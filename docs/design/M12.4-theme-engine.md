# M12.4 — Theme Engine & Theme Studio

**Status:** Expanded implementation pushed for maintainer verification  
**Base:** M12.3 adaptive shell and the user's pushed follow-up fixes  
**Technology:** PySide6 + Qt Quick/QML; no WebView or Node.js

## Product direction

Miselium's Theme Studio provides a functional four-anchor palette explorer and saved-theme workflow. It is a native Qt Quick implementation; Tailwind CSS, browser CSS, and WebView are not introduced.

## Scope

### M12.4.1 — Theme Engine core
- Central `ThemeController.qml` is the single source of truth for semantic visual tokens.
- Appearance mode, visual style, palette anchors, and saved themes persist through Qt `Settings`.
- Supported styles: Industrial Professional, Minimalist, Claymorphism, Aurora, Brutalist, and Industrial Dark.
- System, Light, and Dark appearance modes.
- Glassmorphism is not offered as an application theme. Live backdrop blur is intentionally excluded from the mobile-first shell to avoid inconsistent appearance and GPU cost on Android.

### M12.4.2 — Four-anchor Color Palette Explorer
- Curated palette catalog includes Office Blue, Ocean Teal, Violet Focus, Warm Earth, Forest System, Graphite Lime, Aurora, Clay Studio, Brutalist Signal, Arctic, Rose Quartz, Midnight Mint, Retro Terminal, Pastel Bloom, Neon Pulse, Monochrome Pro, Corporate Trust, and Citrus Lab.
- Each palette has four functional anchors: Brand, Accent, Background, and Border.
- Filters: color harmony, 13 design vibes, and Light/Dark compatibility.
- Palette selection uses a dropdown instead of a long card gallery. Each option shows the palette metadata and its four colors.
- Palette application updates the four anchors. Light-only and Dark-only palettes also select the matching appearance mode; Both leaves the current mode unchanged.
- A custom four-anchor editor uses a native color picker with HEX validation for each anchor.
- Contrast ratio is shown against white with an AA guidance threshold for normal text.

### M12.4.3 — Theme Application menu
- Theme controls live under Settings → Tema Aplikasi.
- The Settings shell exposes Tema Aplikasi, Operasional, Perangkat, and Antarmuka as separate menu destinations.
- Controls update the shared ThemeController immediately.
- Users can save, apply, overwrite by name, and delete personal theme snapshots.
- Saved theme snapshots include style, appearance, and the four palette anchors.
- Theme preferences and saved themes persist locally through Qt Settings.
- Legacy Glassmorphism preferences and saved themes are normalized to Industrial Professional.

### M12.4.4 — Semantic-token migration
- Main application shell continues to consume the shared controller.
- Dashboard, Camera & Scanner, and Settings pages receive the same controller instance.
- Major page surfaces, text, status colors, borders, and card/control radii reference semantic tokens.
- Camera viewfinder remains a dark preview canvas by design so camera output remains legible.

## Local verification checklist

Run `python main.py` and verify:

1. Switch all six visual styles and System/Light/Dark modes.
2. Open Settings → Tema Aplikasi and confirm the other Settings menus remain reachable.
3. Filter palettes by Harmony, Style/Vibe, and compatibility; select palettes from the dropdown.
4. Confirm all four palette anchors update through the color picker and malformed HEX values are rejected.
5. Check the brand contrast guidance.
6. Save a named theme, apply it, overwrite it, delete it, and restart the app to confirm persistence.
7. Verify Dashboard, Camera & Scanner, Settings, navigation, and camera/scanner actions remain functional.
8. Check compact phone widths (360–430 logical px), tablet widths, and desktop widths.
9. Check text readability and contrast in Light and Dark modes, especially Claymorphism.

Run repository checks:

```bash
pytest -q
ruff check .
```

Runtime validation on Linux, Windows, or a physical Android device is not claimed by this change. The repository maintainer will perform that verification before merge.

## Audit follow-up (2026-11-19)

- Dark Claymorphism uses dark surfaces with light text; Aurora now resolves to distinct light and dark semantic surfaces.
- Restoring older or malformed saved themes falls back to safe defaults for missing/invalid values.
- Dashboard, Settings, Camera, and Theme Studio content now sizes from the available `ScrollView` viewport. Camera actions and image-preview controls adapt to compact widths.
- Glassmorphism was removed from the application theme list. Legacy `visualStyle` and saved-theme values are normalized to Industrial Professional; obsolete glass fields are ignored.
- The PostgreSQL CI command now uses the repository-root `tests/backend/` paths. Those paths were stale in the M12.3 baseline; this correction is not an M12.4 backend change.
- Linux offscreen checks cover QML loading and 360x640 layouts. Windows, physical Android performance/touch behavior, and PostgreSQL restricted-role execution still require CI or device/service validation.
- PR #11 currently uses the M12.3 feature branch as its base. Retarget it to `main` before merge so its comparison includes the complete M12.3 and M12.4 implementation.
