# M12.4 — Theme Engine & Theme Studio

**Status:** Expanded implementation pushed for maintainer verification  
**Base:** M12.3 adaptive shell and the user's pushed follow-up fixes  
**Technology:** PySide6 + Qt Quick/QML; no WebView or Node.js

## Product direction

Miselium's Theme Studio adopts the interaction model of a visual glass-material editor and a functional four-anchor palette explorer. It is a native Qt Quick implementation; Tailwind CSS, browser CSS, and WebView are not introduced.

## Scope

### M12.4.1 — Theme Engine core
- Central `ThemeController.qml` is the single source of truth for semantic visual tokens.
- Appearance mode, visual style, palette anchors, glass parameters, and saved themes persist through Qt `Settings`.
- Supported styles: Industrial Professional, Glassmorphism, Minimalist, Claymorphism, Aurora, Brutalist, and Industrial Dark.
- System, Light, and Dark appearance modes.

### M12.4.2 — Four-anchor Color Palette Explorer
- Curated palette gallery includes Office Blue, Ocean Teal, Violet Focus, Warm Earth, Forest System, Graphite Lime, Aurora, Clay Studio, Brutalist Signal, Arctic, Rose Quartz, and Midnight Mint.
- Each palette has four functional anchors: Brand, Accent, Background, and Border.
- Filters: color harmony, 13 design vibes, and Light/Dark compatibility.
- Palette application updates the four anchors. Light-only and Dark-only palettes also select the matching appearance mode; Both leaves the current mode unchanged.
- A custom four-anchor editor accepts validated six-digit HEX colors.
- An 11-step shade scale is derived independently from each of the four anchors.
- Contrast ratio is shown against white with an AA guidance threshold for normal text.

### M12.4.3 — Glassmorphism Editor
- Controls: blur, background opacity, border opacity, radius, saturation, shadow intensity, spotlight size, spotlight opacity, spotlight enablement, base glass color, spotlight color, and preview background color or image.
- A native Qt Quick Effects `MultiEffect` blur/saturation preview is used in Theme Studio; no browser CSS or WebView is involved.
- The editor previews tint, opacity, edge, and radius over a colorful background.
- Blur/saturation are retained as design tokens. The current page-level application surfaces use translucent material tokens; full backdrop sampling for every page card/dialog is a separate rendering integration and is not claimed complete here.
- Heavy effects remain confined to the editor preview to avoid imposing an unmeasured graphics cost on every mobile surface.

### M12.4.4 — Theme Studio and saved themes
- Theme Studio is embedded in application Settings.
- Controls update the shared ThemeController immediately.
- Users can save, apply, overwrite by name, and delete personal theme snapshots.
- Saved theme snapshots include style, appearance, four palette anchors, and all Glassmorphism settings.
- Theme preferences and saved themes persist locally through Qt Settings.

### M12.4.5 — Semantic-token migration
- Main application shell continues to consume the shared controller.
- Dashboard, Camera & Scanner, and Settings pages receive the same controller instance.
- Major page surfaces, text, status colors, borders, and card/control radii reference semantic tokens.
- Camera viewfinder remains a dark preview canvas by design so camera output remains legible.

## Local verification checklist

Run `python main.py` and verify:

1. Switch all seven visual styles and System/Light/Dark modes.
2. Filter palettes by Harmony, Style/Vibe, and compatibility; apply Light, Dark, and Both palettes.
3. Confirm all four palette anchors update and custom HEX validation rejects malformed values.
4. Check the 11-step brand scale and contrast guidance.
5. Adjust each Glassmorphism slider, colors, and spotlight; verify the native blur/saturation preview updates.
6. Save a named theme, apply it, overwrite it, delete it, and restart the app to confirm persistence.
7. Verify Dashboard, Camera & Scanner, Settings, navigation, and camera/scanner actions remain functional.
8. Check compact phone widths (360–430 logical px), tablet widths, and desktop widths.
9. Check text readability and contrast in Light and Dark modes, especially Glassmorphism and Claymorphism.

Run repository checks:

```bash
pytest -q
ruff check .
```

Runtime validation on Linux, Windows, or a physical Android device is not claimed by this change. The repository maintainer will perform that verification before merge.
